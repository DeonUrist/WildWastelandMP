## Cause and implementation

`WheelArms.Tick` assumed the first child of native `steering.steeringWheel` was a fitted wheel with an XY rim. Crossbreed-derived motorcycles instead have headlight/radio mounts and a separate `steering front` assembly. The old binding therefore retained the static seat arms. Native `Steering.CalculateSteerAngles` consumes input independently of whether a removable steering wheel is installed.

Source evidence: `Sources/data/hierarchy/prefabs/C/Crossbreed.txt:154` describes the moving assembly and its clutch/throttle meshes; the VehicleController at line 27 binds `steering_parent/steering_hinge`. Halfbreed binds its rear `steering_parent_R/steering_hinge`, with the same grip meshes at lines 247/250. The converted Motorcycle retains the Crossbreed assembly (`Patrols/Vehicles/Motorcycles/Factory.cs`). `Sources/code/NWH.VehiclePhysics2/NWH.VehiclePhysics2/Steering.cs:74` reads steering input and line 138 begins native visual rotation. Current host/client logs show attached steering-wheel parts but contain no enabled wheel-IK trace, so they do not establish visual acceptance.

- `Vehicles/WheelArms.cs`: bind fixed clutch/throttle mesh centres, track their live transforms and apply the existing rigid two-bone IK after the seated pose. Slight spine yaw follows actual steering angle (one quarter, capped at eight degrees); hands stay attached instead of using a car's alternating rim regrips. Weapon/throw/binocular/native-arm ownership and right-hand tool ownership remain in force.
- `Vehicles/WheelGripEditor.cs`: the existing Steering-wheel hands page/numpad editor adjusts motorcycle hand/wrist/shoulder/elbow offsets. Fixed grips use the existing SIDE fields; unused TOP/rim/regrip controls are hidden. Model-specific `handlebars-<chassis prefab ID>.txt` profiles use the existing 60-value file format under `PlayerBody/WheelGrips`. Existing profiles and custom files are retained; files are written only by the editor's existing save actions.
- `Body/Body.cs`: the existing passenger knee-rest arm solver also handles a local driver's missing removable steering wheel. The driver remains in the driver's seat, with all normal driving controls except steering.
- `PlayerBodyModule.cs`: register a PlayerBody-owned prefix on `Steering.CalculateSteerAngles`. It clears steering input only for the cached local driver when native `hinge_steeringwheel` has no active attached `vehPart`. Native steering, smoothing and centering still run. Fixed handlebars, passengers, AI and remote vehicles are outside that guard.

The existing MP mode-3 pose capture follows final local IK and carries the body/arm result. No protocol, configuration entry, save key, component or prefab-ID changes. No new scheduler job or steady-state allocation; grip geometry and bones are cached. Visual fit and performance require Denis's game test; unreachable grip targets retain the existing bone-length limit and can be calibrated in the editor.
