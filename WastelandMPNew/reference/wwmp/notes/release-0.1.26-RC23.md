# Wild Wasteland 0.1.26 RC23

This experimental RC includes all changes since RC22: binocular exploration and identification, Stew Pot integration, automatic standalone replacement, settings updates and the first Performance module pass. Features awaiting gameplay verification remain Testing.

- Binoculars hide the HP/weapon/slot panels and remember 1–2x additional mouse-wheel magnification. Normal fog reveal reaches twice its former radius. The binocular view cone extends to 2x normal exploration range; a scoped sniper extends fog only to 1.5x. Scopes never identify targets or show names. Weapon ironsight wheel magnification caps at 3x.
- Looking through binoculars identifies unobstructed POIs and physical patrol/traveler groups. Identified traffic gains its real map name/color in Ambiguous mode for that group's current lifetime, including after virtual travel. Observation works with compass markers off. Fog and Off settings still control map visibility. A colored caption appears below the binocular view; location captions use capitalized names without numeric IDs, such as Camp or Cave. Captions now anchor to the screen canvas instead of the oversized native mask.
- World traffic markers independently offers Off / Ambiguous / On (default Ambiguous), separate from location markers and route lines. Existing traffic settings migrate. Foot travelers retain moving map dots/names without route ink or compass markers.
- Survival integrates Stew Pot 0.1.1 with its original prefab ID and native save fields. It supports filling, drinking, meat, cooking, insanity removal and spoilage. Tilt spilling/pot-to-pot pouring is off by default; Enable Debug exposes Allow stew pot spilling under F3 Debug > Switches > Survival. Native can filling and drinking remain available. Models, textures and boiling audio are included; missing defaults extract without overwriting custom files.
- Replaced standalones are queued for disable through Apocasetter's existing installer, preserving configs and recoverable files. The title menu names/counts replacements and requests a restart. WW waits until that restart to take over. Without a usable installer, the notice gives manual-disable instructions. Optional Talk, Quests, Engine Sim, ChaseCamera and Apocapocket are not replacements and are not bundled.
- F3 Debug begins with patrol editor access, logging and switches. Its final Developer mode checkbox reveals a separate Developer page for advanced tools/settings. Both require Enable Debug in F6. Clean HUD and Clean menus switches move to Debug. Game/HUD starts with crosshair and hit feedback. Driving instruments offer Off / 3rd person / On, defaulting to third-person only while preserving existing settings.
- Player previews and native TAB/tutorial portraits share editable transparent male/female PNGs. The male default is included and extracted only when missing. Portraits survive Low preset texture-limit changes; borrowed image references restore when the feature is disabled.
- Quests compatibility warns and attempts integration for versions other than the 1.8.0 baseline, including the installed 1.8.2, rather than rejecting the version alone. Missing runtime hooks still fail normally; quest saves and source-mod ownership remain unchanged.
- The Performance module adds experimental PlayMaker, game-logic, rendering and world optimizations with presets and a separate F3 page. Earlier committed follow-ups pace vehicle assembly, queue NPC rigs and refine runtime hooks. Individual features and visual/performance results still need Denis's in-game validation; no general performance improvement is claimed by this release.

Install the full archive into `BepInEx/plugins`, preserving customized external assets. It carries forward RC22's models, climbing/dog bundles, sounds, theme, icons and loading screens, plus the new Survival defaults and male portrait. Do not install optional dependencies from another user's plugin folder.

## Check after installing

1. Confirm `Loading [Wild Wasteland 0.1.26]`, inspect module/job errors, and complete any standalone-replacement restart before entering gameplay. Optional compatibility mods should remain installed.
2. With ambiguous traffic enabled, observe a patrol, foot travelers and an existing POI through binoculars. Check the bottom-center colored caption and real map names/colors. Lower/reopen binoculars and restart to check remembered zoom. Location captions should say Camp/Cave/Building/Wreck without numbers.
3. Explore fresh directions while stationary: with default settings compare about 1 km normal, 1.5 km scoped and 2 km binocular range. A scope must neither identify unknown targets nor show a caption. Save-and-quit/reload to check exploration persistence.
4. Inspect Debug/Developer visibility, independent map controls, driving HUD choices and transparent male/female portraits, including after changing the Performance preset.
5. With Survival active, spawn a pot through optional Apocaspawner, fill/drink/cook, and save/reload an existing pot. Verify no spills with the default switch, then test enabling/disabling pouring. Use the detailed checks in `notes/port-Survival.md` and `notes/replacement-guard.md`.
6. Check the installed Quests version's dialogue, tracker, journal, notifications and follower behavior. Compare Performance presets in actual play; retain individual experimental switches only after testing.

Verification is the Windows Release build/deploy with zero errors. In-game and performance verification remains with Denis. No issues are closed, no features are promoted to Verified, and the Apocasetter index is unchanged.
