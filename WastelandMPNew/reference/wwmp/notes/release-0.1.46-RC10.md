# Wild Wasteland MP RC10 (0.1.46) — Purchases, collision protection and autosave warnings

- **Purchased items:** fixes a shop item still showing Buy to the host or another guest after a client buys it. The shared item-edit path now finishes the native purchase interaction on observers as well as synchronizing the purchase flag, restoring normal Take/use behavior without replaying payment. Applies to items using the native shop purchase flow, including flashlights, equipment, supplies and vehicle parts.
- **Occupant collision protection:** the existing **Ram damage in car** switch defaults off and now also blocks native crash damage to the driver. Existing protection from AI rams covers player drivers and passengers. Explicit saved On choices are retained; switch it off for protection. Vehicle parts can still take damage, and this does not grant protection from gunfire or other combat damage. This closes a damage-policy bypass; it does not establish or claim to fix the reported backward downing/desync cause.
- **Autosave warning:** **SYSTEM > Warning seconds** accepts **0–120**, keeping default 30. Set 0 to disable countdown/deferred/final warnings and their final three-second delay. Enabled warnings use one updating row in the transparent top-left message log, with a transparent top-left fallback when CleanHUD is off. Removes the central dark panel and duplicate countdown chat notices. Combat and driving safety gates still apply at 0.

No new settings keys, save formats or protocol changes; handshake 24 remains. All players must update/restart with matching WWMP builds. Install the full ZIP into `BepInEx/plugins`, keeping standard Wild Wasteland disabled. Multiplayer requires separately installed **BepInEx 5 x64** and [Apocalypter Multiplayer 0.4.1](https://www.nexusmods.com/apocalypter/mods/10); dependency DLLs are not bundled. Offline saving remains independent of the multiplayer dependency.
