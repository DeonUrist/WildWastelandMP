Important source finding: MP WorldObjects.ItemsTick calls Vars.Revert while QuietUntil is active or ShouldSendVars is false. Host ShouldSendVars accepts only Owner==0; the guest accepts locally owned objects or nearby interaction objects. Host OnVars rejects another peer's changes to a remotely owned item. Direct WW condition writes can therefore disappear or fail to reach the owner. This needs a defined authority/ordering path, not another visual-only snapshot.

Inspect the existing MP decompile under the external dossier rather than regenerating it: Net.ItemVars.For/Write/Apply/Rebase, WorldObjects.ItemsTick/ShouldSendVars/OnVars/ApplyVars, WriteState/ReadState/FindAttachment/ApplyAttachment/ownership handlers and enabled-FSM/usable interaction relay. Use Sources/systems/vehicles.md and indexed prefab FSMs for native values. Do not read huge source dumps whole.
